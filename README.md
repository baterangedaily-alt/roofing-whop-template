# US Roofing Pro - Whop Websites Template

Production-ready US roofing template built on Whop Websites.

## Bounty Requirements Met
- Whop Websites: deployable to *.whop.site
- Whop Payment Element: data-whop-payment-plan="deposit_149_once" ($149 once)
- Whop Pay Element: data-whop-pay="full_service_once" ($999 once)
- Request Estimate form wired to Whop Leads API: https://api.whop.com/api/v2/leads
- 3 Plans: Free Guesstimate $0 once, Inspection Deposit $149 once, Full Roof Service $999+ one-time
- 3 Tracking Events: estimate_started, deposit_paid, service_viewed via whop.track()
- Mobile responsive
- Reusable: change company name, city, colors for any US roofer

## Whop Product
Product: US Roofing Company Website Template
